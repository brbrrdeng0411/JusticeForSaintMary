# JusticeForSaintMary

《승리의 여신: 니케》 4주년 캐릭터를 모티브로 한 **비영리 팬게임 단일 HTML 프로토타입**입니다.

## 실행
`index.html`을 브라우저에서 엽니다. CDN·별도 설치·서버 없이 실행되는 실험용 빌드입니다. 파일에서 세이브 저장이 제한되는 브라우저를 대비하여 **기록/세이브 → JSON 내보내기**를 제공합니다.

## 규칙
- 라피(레드 후드)로 시작. 4스테이지 보스는 라푼젤(생츄어리) → 홍련(신살) → 도로시(4주년 서사) → 마리안(퀸).
- 전투 전 6장 덱 구성, **매 턴 3장 드로우 → 플레이어가 1장 직접 사용**, 총 12턴.
- 호조, 호인상, 방밀, 온강 카드의 조합과 고유 액티브/패시브로 목표 점수 돌파.
- 각 스테이지에서 새 카드 해금. 4스테이지 완주 때 미해금 보스 1명 플레이어블 선택; 세 번 완주 후 4명.
- 세이브 자동 저장·JSON 백업/복원. 카드 제작·실험실에서 자기 카드 제작/테스트.

## 파일
- [HANDOFF.md](HANDOFF.md): 현재 기획·구현·후속 작업 인수인계.
- [TEST_REPORT.md](TEST_REPORT.md): Playwright 브라우저 테스트 382개 assertion 결과.
- [LICENSE](LICENSE): 독자 작성 코드와 문서의 비영리 팬 전용 소스 공개 조건.
- `index.html`: 실행 가능한 게임.

## 개발 상태
이번 빌드는 4주년 분위기의 색과 임시 실루엣을 사용합니다. 원작 이미지·음원·로고는 포함하지 않았습니다. 엔딩/대사는 제작자 직접 검수 전 placeholder입니다.

## 원작 권리
코드의 소스 공개 조건과 원작 IP 이용허가는 서로 다릅니다. 시프트업 [2차 창작 가이드라인](https://policy.shiftup.co.kr/ip/kr/index.html) 제3조 3항에는 게임 IP를 이용한 게임 제작·배포·서비스가 원칙적으로 허용되지 않는다는 문구가 있습니다. 본 저장소의 라이선스가 원작 사용 허가를 대신하지 않습니다.
